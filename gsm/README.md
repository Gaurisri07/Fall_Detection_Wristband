# /gsm — GSM Alert Dispatch Module

## Scope
This module owns the SIM800L cellular modem integration over UART.

## Responsibilities
- Manage SIM800L power and cellular network registration.
- Format emergency SMS payloads containing fall alert notifications and Google Maps GPS links.
- Send SMS messages to emergency contacts and initiate voice calls if configured.
